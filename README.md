# Ecommerce Application UI

This is the frontend user interface for the Ecommerce application. It is a modern, fast, and scalable single-page application built with React, TypeScript, and Vite, designed to connect seamlessly with our robust REST API backend.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Linting**: [ESLint](https://eslint.org/)

## ✨ Key Features

This frontend application is designed to interface with our secure backend services and provides the following features:

- **Secure Authentication**: Integration with JWT-based authentication for secure user sessions and role-based access.
- **Shopping Cart Management**: Dynamic cart state handling allowing users to add, update, and remove items efficiently.
- **Order Processing & Checkout**: A streamlined checkout flow supporting address selection, inventory validation, and seamless order creation.
- **Product Catalog**: Serves the required pages for dynamic product discovery, search, and detailed viewing.

## 🛠️ Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher is recommended) along with npm.

### Installation

1. Navigate to the project directory:
   ```bash
   cd ecommerce-ui
   ```

2. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Application Locally

To start the Vite development server:

```bash
npm run dev
```

The application will be accessible at `http://localhost:5173` (or another port if specified in the terminal).

### Available Scripts

- `npm run dev`: Starts the local development server with Hot Module Replacement (HMR).
- `npm run build`: Compiles the TypeScript code and bundles the application for production.
- `npm run preview`: Locally previews the production build generated by the `build` script.
- `npm run lint`: Runs ESLint to find and fix problems in the JavaScript/TypeScript code.

## 🔗 Backend Integration

This application relies on a backend REST API. Ensure that the backend server (handling Prisma database operations, Argon2 password hashing, and Passport.js JWT authentication) is running concurrently for full functionality. Configure any necessary environment variables (like API base URLs) in a `.env` file based on your backend setup.
